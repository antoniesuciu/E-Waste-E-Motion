# Production context and sources

Verified against primary sources on 3 November 2026. Technical claims about this repository are documented separately in [architecture.md](architecture.md).

## Production

The [official theatre project page](https://www.teatrulgeorgeciprian.ro/e-waste-e-motion/) credits Antonie Amir Suciu for robot and lighting programming and lists the complete production team. Its implementation period is 27 March–15 November 2025. The README reproduces the relevant creative credits.

The [English project brochure](https://www.teatrulgeorgeciprian.ro/wp-content/uploads/2025/12/EN-E-Waste-E-Motion-project-brochure.pdf), particularly PDF pages 5 and 8–10, describes eight custom-built robots, lighting, video displays, and movement/audio scores coordinated through timing. Those are production details; not every production component is present in this archive. Programmed motion should not be confused with the separate use of AI for voices.

Participant Cristina Bodnărescu's [portfolio](https://www.ethicsofjoy.com/portfolio-collections/selectie/e-waste-e-motion-robot-theatre) records September 2025 presentations in Buzău, at CINETic in Bucharest, and in Constanța. It links the [recorded performance with English subtitles](https://www.youtube.com/watch?v=oUAgcPvxwfg), also linked by the theatre. The link destination was checked through those sources; video playback was not tested.

## Audience research

The user supplied the [English audience-experience report](https://www.teatrulgeorgeciprian.ro/wp-content/uploads/2026/06/EN-Audience-experience-analysis-E-Waste-E-Motion-v2.pdf). The cover is dated **12 November 2025**, regardless of the `/2026/06/` upload path. It identifies the document as a working translation made with AI.

The report records 342 spectators across three cities and 65 questionnaire respondents. Questionnaires were administered in Bucharest and Constanța only. This provides context for the production, not a benchmark or validation result for the control software. No audience satisfaction statistic is used as a software quality claim.
